# Анализ результатов A/B-тестирования (CTR)

Информационно-аналитическое приложение с графическим интерфейсом (Tkinter)
для анализа результатов A/B-тестирования по показателю конверсии (CTR).
Разработано в рамках курса «Проектный семинар „Python в науке о данных“».

## Возможности

- Загрузка исходных данных из CSV (формат Kaggle ab-testing).
- Очистка данных: удаление дубликатов и некорректных строк
  (например, `control` + `new_page`).
- Просмотр, добавление, редактирование и удаление записей в таблице.
- Сохранение и загрузка очищенных данных в двоичном формате (`.pkl`).
- Расчёт CTR по группам и проверка значимости различий (Z-критерий долей).
- Формирование отчётов:
  - текстовый отчёт `.txt`;
  - столбчатая диаграмма CTR `.png`;
  - круговая диаграмма распределения групп `.png`.
- Все параметры настраиваются через `config.ini`.

## Структура проекта

```
work/
├── config.ini            # конфигурация приложения
├── data/                 # исходный CSV, справочники, двоичный файл
│   ├── ab_data.csv
│   ├── groups.csv        # справочник групп (3НФ)
│   └── pages.csv         # справочник страниц (3НФ)
├── graphics/             # графические отчёты (.png)
├── library/
│   └── utils.py          # универсальные функции (данные, статистика, I/O)
├── notes/                # документация
├── output/               # текстовые отчёты (.txt)
└── scripts/
    ├── main.py           # главный исполняемый скрипт (GUI)
    └── reports.py        # функции построения отчётов
```

## Системные требования

- Python 3.8+
- NumPy, Pandas, Matplotlib
- Tkinter (входит в стандартную поставку Python)

Установка зависимостей:

```bash
pip install numpy pandas matplotlib
```

## Запуск

Из корневого каталога `work`:

```bash
python scripts/main.py
```
